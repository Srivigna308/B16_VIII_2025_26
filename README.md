# B16_VIII_2025_26
Implementation of LiDAR‑based 3D object detection using PointNet, VoxelNet, and PointPillars. Includes preprocessing pipelines, training scripts, evaluation metrics, and visualization outputs on KITTI and Toronto‑3D datasets.
Object Detection Using LiDAR Point Cloud Data
This repository contains the implementation of our final year BE IT project on LiDAR‑based 3D Object Detection. The work explores deep learning architectures such as PointNet, VoxelNet, and PointPillars, applied to benchmark datasets like KITTI and Toronto‑3D.

 Features
Preprocessing pipeline for raw LiDAR point clouds.

Implementation of PointNet, VoxelNet, and PointPillars models.

Training and evaluation scripts with metrics (Accuracy, Precision, Recall, IoU, AP).

Visualization tools for point clouds, bounding boxes, and detection outputs.

Comparative analysis of model performance in terms of accuracy, latency, and robustness.

⚙️ Tools & Libraries
Deep Learning: PyTorch, TensorFlow

Point Cloud Processing: Open3D, PCL

Visualization: Matplotlib, Seaborn, TensorBoard

Datasets: KITTI Vision Benchmark Suite, Toronto‑3D

Hardware Acceleration: CUDA/cuDNN

📊 Results
Comparative accuracy graphs for PointNet vs VoxelNet.

KITTI and Toronto‑3D detection outputs with bounding boxes.

Performance evaluation including confusion matrices, classification reports, and IoU scores.
